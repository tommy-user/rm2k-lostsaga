승급

    승급 기술

      초기 능력치

      배우는 기술 레벨업

      Lv기술MP설명

      몬스터로 태어나기

      어둠의 종족 몬스터는 승급 대신 진화한다. 슬라임으로 시작해 오크나 좀비를 거쳐, 마지막 진화를 마치면 쉐도우가 카오스의 옛 왕좌로 데려가 각성 의식을 치른다.

      밤에는 안티프리스트, 도적, 닌자와 함께 능력치가 오른다.

      진화 경로

      1. 슬라임 Lv5 에 오크나 좀비로
      2. 오크 Lv10 에 오크로드 → 오크나이트, 또는 하피 → 뱀파이어 → 뱀파이어로드
      3. 좀비 Lv10 에 스켈레톤 → 스켈톤워리어, 또는 고스트 (하피 길로)
      4. 오크나이트·스켈톤워리어 오크마스터·스켈톤나이트를 거쳐 쉐도우로, 또는 뱀파이어로드로
      5. 쉐도우 Lv45 에 나이트마스터나 드래곤마스터로. 뱀파이어로드는 다크마스터로
      6. 왕좌의 각성 Lv50. 다크마스터는 엘더리치·카오스마스터, 나이트마스터는 데스나이트·다크나이트, 드래곤마스터는 슬레이어·하프드래곤
