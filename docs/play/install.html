앱으로 설치하기

설치하면 홈 화면이나 바탕화면 아이콘으로 주소 입력 없이 바로 열 수 있습니다. 설치하지 않아도 게임은 똑같이 할 수 있습니다.

설치 전에 확인하세요

iPhone·iPad의 홈 화면 앱은 Safari와 저장 공간이 따로입니다. 게스트로 하던 세이브는 앱에서 보이지 않습니다.

설치 전에 Google 계정을 연결해 두면, 앱에서 같은 계정으로 로그인해 이어 할 수 있습니다.

안드로이드와 컴퓨터는 브라우저와 같은 저장 공간을 씁니다.

iPhone · iPad (Safari)

  1. Safari로 이 게임 주소를 엽니다.
  2. 아래쪽(iPad는 위쪽)의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 고릅니다.
  4. 이름이 로스트사가인지 보고 추가를 누릅니다.
  5. 홈 화면의 아이콘으로 엽니다. Google 계정을 연결했다면 Google로 로그인합니다.

안드로이드 (Chrome)

  1. Chrome으로 게임 주소를 엽니다.
  2. 홈 화면에 나오는 설치 버튼을 누릅니다. 안 보이면 오른쪽 위 ⋮ 메뉴에서 앱 설치(또는 홈 화면에 추가)를 고릅니다.
  3. 확인창에서 설치를 누릅니다.

컴퓨터 (Chrome · Edge)

  1. 게임 주소를 엽니다.
  2. 주소창 오른쪽의 설치 아이콘을 누르거나, 홈 화면의 설치 버튼을 누릅니다.
  3. 확인창에서 설치를 누르면 별도 창으로 열립니다.
