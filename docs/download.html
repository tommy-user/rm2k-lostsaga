실행 방법

받은 zip 의 압축을 먼저 풉니다. 안에 rm2k-lostsaga 폴더가 있고, 이 폴더가 게임입니다. 기기에 맞는 방법을 고르세요.

Windows

  1. zip 압축을 풀고 로스트사가 접속.exe 를 실행합니다.
  2. 그림이나 소리가 나오지 않으면 RPG Maker 2000 런타임 패키지(RTP)가 필요합니다. RTP 설치 파일을 받아 설치하세요.
  3. 실행이 되지 않거나 느리면 아래 EasyRPG Player 로 실행할 수 있습니다.

EasyRPG Player 로 실행하기

EasyRPG Player 는 RPG Maker 2000 게임을 여러 기기에서 돌려 주는 무료 프로그램입니다. 설치한 뒤 위에서 받은 게임 폴더를 열면 됩니다. 공식 다운로드 페이지

  • Windows: 공식 페이지에서 받은 zip 의 실행 파일을 게임 폴더(rm2k-lostsaga) 안에 넣고 실행합니다.
  • Mac: 공식 페이지의 macOS 앱을 받거나 터미널에서 brew install easyrpg-player 를 한 뒤, 게임 폴더(rm2k-lostsaga) 안에서 easyrpg-player 를 실행합니다.
  • Linux: Flatpak(org.easyrpg.player) 이나 배포판 패키지로 설치하고 게임 폴더에서 실행합니다.

Android

  1. Google Play 의 EasyRPG Player 를 설치합니다.
  2. 받은 zip 의 압축을 풉니다. (ZArchiver 같은 압축 앱을 쓰세요. 앱이 zip 을 직접 열지 못할 수 있습니다.)
  3. 풀린 rm2k-lostsaga 폴더를 easyrpg/games/ 폴더 안으로 옮깁니다. 앱 첫 화면의 안내에 나오는 게임 폴더 위치를 따르세요.
  4. EasyRPG Player 를 열고 목록에서 로스트사가를 눌러 시작합니다.
  5. 그림·소리가 비어 보이면 RTP 를 easyrpg/rtp/2000/ 에 넣어야 합니다.

화면에 십자키와 버튼이 나타나 터치로 조작할 수 있습니다. 기기와 앱 버전에 따라 폴더 위치와 메뉴 이름이 조금 다를 수 있습니다.

iPhone · iPad (iOS)

EasyRPG Player 는 앱스토어에 정식 앱이 없습니다. iOS 에서는 RetroArch 앱에 EasyRPG 코어를 받아 쓰는 방법이 있습니다.

  1. 앱스토어에서 RetroArch 를 설치하고, 코어 다운로드에서 EasyRPG 를 받습니다.
  2. 압축을 푼 rm2k-lostsaga 폴더를 파일 앱의 RetroArch 폴더로 옮깁니다.
  3. RetroArch 에서 콘텐츠 불러오기로 폴더 안의 RPG_RT.ldb 를 고릅니다.

iOS 는 설치 환경에 따라 동작이 달라 여기서는 확인하지 못했습니다. 안 되면 문의로 알려 주세요.

이미 하고 있다면 (업데이트)

  1. 위에서 새 zip 을 받아 압축을 풉니다.
  2. 풀린 파일을 지금 쓰는 rm2k-lostsaga 폴더에 덮어씁니다.
  3. 게임을 켜고 이어하기를 합니다.

세이브(Save01.lsd 같은 파일)는 zip 에 없어서 덮어써도 그대로 남습니다. 그래도 불안하면 Save 로 시작하는 파일만 따로 복사해 두세요. 이어하기가 안 되는 버전이 있을 수 있으니 릴리즈 노트도 한 번 봐 주세요. Android 는 세이브가 게임 폴더 밖에 있을 수 있어, 덮어쓰기 전에 위치를 확인하세요.
